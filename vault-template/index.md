# Vault index

Catalog: file → one-line summary. Complements the routing table in AGENTS.md (which maps *requests* to files; this
maps *files* to contents). Update on every note creation, rename or archival; skip individual files in `inbox/` and
`archive/`.

- [CLAUDE](CLAUDE.md) — one line importing AGENTS.md for Claude Code
